# Meetings

[[Home]] · [[Follow-ups]] · [[90 System/Templates/Standup|Standup template]] · [[90 System/Templates/Meeting|Meeting template]]

Create a note in `05 Journal/Meetings`, name it `YYYY-MM-DD HHmm - Topic`, then insert **Standup** or **Meeting** with **Ctrl+Alt+T**. Set the date, attendees, and project. Record decisions and actions before polishing minutes.
